# Narrated Explainer Video Bot

Turn rough points into a 3Blue1Brown-style narrated explainer: aesthetic, segmented script, critique, and HTML slides.

## When to use
Use when the user wants to produce a short explainer video and needs the script + slides authored for them.

## Inputs
- A topic and rough bullet points.

## How it works
Picks a consistent visual aesthetic, writes a 4-8 segment spoken-style script, self-critiques it (understandability / analogies / wonder), and designs one self-contained 1920x1080 HTML slide per segment. Voice recording + MP4 assembly happen locally (see the repo).

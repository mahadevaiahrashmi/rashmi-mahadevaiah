# JD-to-Resume Customizer

Tailor a resume and cover letter to a specific job description, re-emphasizing real experience — never inventing it.

## When to use
Use when the user has a target job description and wants a one-page resume + matching cover letter aligned to it.

## Inputs
- The job description.
- The user's existing resume / experience.
- Choice of AI engine (OpenAI / Claude / Gemini via OpenRouter).

## How it works
Maps the JD's requirements onto the user's real experience, reorders and rewrites bullets to match, and renders downloadable Word + PDF. Guardrail: re-emphasizes existing facts, never fabricates roles or skills.

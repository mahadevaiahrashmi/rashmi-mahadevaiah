# Personal Voice

Learn a person's writing voice from a few samples, then draft replies, posts, and messages that sound like them.

## When to use
Use when the user wants text written *in their own voice* — an email, LinkedIn post, DM, or reply — instead of generic AI phrasing.

## Inputs
- A few writing samples (things the user has actually written).
- The message to draft or the situation to respond to.
- Optional tone nudges: shorter, warmer, more formal.

## How it works
Extracts voice features (sentence length, formality, quirks, punctuation) from the samples, then conditions generation on that profile. One-tap adjustments re-run with a tone modifier. Nothing is stored server-side.
